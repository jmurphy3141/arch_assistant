# POV golden anchor

`POV_PRFAQ_guide.docx` — the SE-provided POV guide. In this methodology a POV is a
"Visionary Press Release" / PRFAQ (Amazon-style working-backwards): the SE imagines
the success press release for the account, then the FAQ. Used by the p78 harness as
the golden exemplar for the `pov` artifact type.

Canonical POV (PRFAQ) structure the producer should hit:
1. Summary — the visionary press release (headline + the future-state narrative)
2. Problem — the customer's pressures/challenges
3. Solution — how OCI addresses them
4. Oracle Quote — a named Oracle leader quote
5. Customer Quote — a named customer executive quote
6. External (Customer) Questions & Answers — the FAQ a customer would ask
7. Internal (Oracle) Questions & Answers — the discovery questions Oracle must answer

Judge POV craft as a PRFAQ: is the press release genuinely visionary and specific;
are the two quotes credible and named; are both FAQ sets the ones a real SE would
use. NOT as a generic "executive summary/brief."

Check for Phase 6: does the pov sub-agent produce this press-release + dual-FAQ
structure? If not, that is a POV structural target parallel to the JEP gap.
